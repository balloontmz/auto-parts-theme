# Release notes

## 1.0.0 — 2026-10

Initial public release of the **Auto Parts** theme.

- Year / Make / Model vehicle picker ("My Garage") in header, hero section and modal
- Catalog fitment via `custom.fitment_*` product metafields + storefront filtering
- Product-page green/red fitment confirmation with compatible-vehicle list
- Universal-fit (`custom.fitment_universal`) product support
- Registered-members-only purchasing gate (optional guest price hiding)
- Dealer / referral attribution via `?ref=` links and cart attributes
- Brand logo strip and vehicle hero sections
- Tailwind CSS v4 build pipeline (compiled, no CDN)
- Based on Dawn 16.0.0 (MIT) — see LICENSE.md
